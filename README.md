# ITRI 616 Mini-Project: Q-Learning Clue-Giving Agent

This repository contains the Python code for my ITRI 616 mini-project.

The project implements a Q-learning clue-giving agent for a South African card guessing game. The agent acts as the clue giver and learns which clues are most effective for different cards and rounds through repeated simulated training.

Full installation, running, and experiment instructions are provided in the submitted Code Documentation and User Guide.
